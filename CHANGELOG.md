# Changelog

## 0.1.0-alpha.1 — implementation draft

- Established the canonical JSON Schema Draft 2020-12 bundle.
- Compiled 266 catalogue items, 30 reusable packs, and 650 per-profile definitions.
- Added the allowlisted declarative comparison vocabulary and stable findings.
- Added Python and TypeScript reference validators, canonicalization, digests, comparison, and fixtures.
- Added additive `model.yaml` examples and deterministic bundle manifests.

This alpha is not GA. Catalogue definitions retain their source review status and are not represented as independently reviewed scientific standards.
