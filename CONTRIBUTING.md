# Contributing

Changes to released objects are not permitted. Corrections create a new
version and must include conformance fixtures.

Profile changes require:

1. a stable identifier and version;
2. machine-readable requirements and comparison rules;
3. positive, negative, and insufficient-evidence fixtures;
4. authoritative scientific sources;
5. a named domain reviewer and review date;
6. confirmation that the profile describes compatibility rather than general
   scientific validity.

Run the complete Python and TypeScript suites before opening a pull request.
Adding an operator requires implementations and identical golden results in
both languages.
